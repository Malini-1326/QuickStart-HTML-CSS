# 🌐 QuickStart - One Page Website

A responsive one-page website built using HTML, CSS, and Bootstrap. This project was developed and customized with a clean layout, responsive design, and reusable web components.

## 📌 Project Overview

QuickStart is a modern one-page website created using HTML, CSS, and Bootstrap. The website is designed to provide a responsive and user-friendly experience across desktop, tablet, and mobile devices.

## 🚀 Key Features

- Responsive one-page website
- Bootstrap-based layout
- Custom CSS styling
- Clean and modern user interface
- Responsive design for different screen sizes
- Image-based website sections
- Mobile, tablet, and desktop support
- Deployed using Netlify

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- Responsive Web Design

## 📂 Project Structure

```text
QuickStart-HTML-CSS/

```

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Malini-1326/QuickStart-HTML-CSS.git
cd QuickStart-HTML-CSS
```

### 2. Open the Website

Open the `index.html` file in your browser.

You can also use the **Live Server** extension in Visual Studio Code.
